# Du.AutoMapper.Collection

此包按配置的等价规则更新已有集合，可以保留匹配元素的对象引用。安装时会解析维护版引擎 `Du.AutoMapper 14.0.0`。

```sh
dotnet add package Du.AutoMapper.Collection --version 11.0.0
```

```powershell
Install-Package Du.AutoMapper.Collection -Version 11.0.0
```

包版本见 [Du.AutoMapper.Collection](https://www.nuget.org/packages/Du.AutoMapper.Collection/)。维护问题请提交到 [维护仓库](https://github.com/dusdong/AutoMapper.Collection/issues)。
